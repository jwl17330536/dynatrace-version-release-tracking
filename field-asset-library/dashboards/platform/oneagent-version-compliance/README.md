# OneAgent Version Compliance

## Overview
Shows installed OneAgent versions and baseline comparison from workflow-collected release data.

## Purpose
When platform teams need to quickly detect OneAgent version drift and support risk, this dashboard highlights current host version distribution against known baseline versions to reduce upgrade triage time.

## Setup
1. Import the dashboard JSON in this folder into your Dynatrace tenant.
2. Confirm companion workflow outputs are available.
3. Share the dashboard with the Use Case Playground User group.
4. Capture and add screenshot.png before contribution PR.

## Notes
- Replace placeholder tenant_url in meta.yaml with the live shared dashboard URL.
- Do not include tokens, credentials, or customer-confidential values.
